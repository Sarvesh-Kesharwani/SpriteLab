# SpriteLab

SpriteLab is a browser-based sprite-animation production pipeline. Import GIFs or videos, crop and extract frames, build golden datasets, isolate sprites, sequence and transform frames, and preview saved animation cycles.

## Local development

```sh
npm install
npm run dev
```

The app uses the browser File System Access API for local workspaces under `D:\SpriteAnimProjects`.

## Build

```sh
npm run build
npm run preview
```
